# 🎮 Trybe Games  

## ✨ Descrição Breve  
Um projeto focado em manipulações e consultas em coleções, utilizando LINQ e testes para operações específicas. O objetivo foi implementar métodos em um software pré-existente, além de aprimorar habilidades de interpretação e desenvolvimento de funcionalidades.

## 🚀 Visualizando localmente  
1. Clone o repositório:  
   ```bash
   git clone https://github.com/Gzuuu/trybe-games.git
   ```  
2. Acesse a pasta do projeto:  
   ```bash
   cd trybe-games/src
   ```  
3. Instale as dependências:  
   ```bash
   dotnet restore
   ```  

## 🛠️ Tecnologias Utilizadas  
- **C#**  
- **LINQ**  
- **.NET**  

## ⚙️ Funcionalidades  
- ✍️ Implementar manipulações em coleções existentes.  
- 🔍 Realizar consultas utilizando LINQ.  
- ✅ Desenvolver e aplicar testes para validar as operações.  
- 📖 Interpretar e trabalhar com código já implementado.  

## 📚 Principais Aprendizados  
- Manipulação avançada de **coleções** em C#.  
- Utilização de **LINQ** para consultas eficientes.  
- Aplicação de **testes** em métodos relacionados a coleções.  
- Habilidade de interpretar e dar continuidade a códigos pré-existentes.
